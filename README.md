#  Инструкция по командной разработке: Проект «Ферма»

Ребята, чтобы мы не затерли код друг друга и не ломали проект, строго соблюдаем этот алгоритм работы с Git.

---

##  0. Установка и первичная настройка Git

Если Git еще не установлен у вас на компьютере:

###  Windows:
1. Скачайте инсталлятор с официального сайта: [git-scm.com/download/win](https://git-scm.com/download/win).
2. Запустите `.exe` файл. Во всех окнах установки можно оставлять настройки по умолчанию (просто нажимайте *Next*).
3. По завершении откройте **PowerShell** или **Git Bash**.

###  macOS:
1. Откройте приложение **Терминал** (Terminal).
2. Введите команду: `git --version`
3. Если Git не установлен, macOS предложит установить Xcode Command Line Tools. Согласитесь.

### ⚙ Первичная настройка (выполняется 1 раз после установки):
Откройте терминал/PowerShell и укажите ваше имя и email (используйте тот же email, что и на GitHub):
```powershell
git config --global user.name "Ваше Имя / Никнейм"
git config --global user.email "your_email@example.com"
```

##  Важно про авторизацию на GitHub
Когда вы впервые попытаетесь сделать `git clone` или `git push`, GitHub может запросить логин и пароль. 
* Старый пароль от аккаунта в консоли **не работает**.
* Самый простой способ при входе в консоли — выбрать авторизацию через браузер (**Sign in with your browser**) или использовать Personal Access Token (токен доступа), если попросит ввести пароль.

##  1. Как скачать (склонировать) проект к себе на ПК
*Важное отличие:* Команда `git init` нужна **только создателю проекта** (один раз при создании). Остальным участникам команды делать `git init` **не нужно** — вы просто клонируете готовый репозиторий!

Когда вас добавили в репозиторий на GitHub (вы приняли приглашение):
1. Создайте папку на компьютере, где будет лежать проект.
2. Откройте **PowerShell** или **Терминал** в этой папке.
3. Скопируйте HTTPS-ссылку репозитория на GitHub (зеленая кнопка **Code**).
4. Выполните команду:
   ```powershell
   git clone https://github.com/ИМЯ_ВЛАДЕЛЬЦА/FarmGame.git
   ```
5. Перейдите в папку проекта:
   ```powershell
   cd FarmGame
   ```
6. Запустите **Unity Hub**, нажмите **Add** -> **Add project from disk** и выберите скачанную папку `FarmGame`.

## 🛠 2. Общие правила перед началом работы
1. Всегда работаем на **своих личных ветках** (никогда не пишем код напрямую в ветку `main`!).
2. Перед тем как начать кодить новый функционал, **обязательно подтяните свежие изменения** из главного репозитория.

---

## 🌿 3. Создание задачи и новой ветки
Каждая новая фича (грядки, инвентарь, багфикс) делается в отдельной ветке.

1. Переключитесь на ветку `main` и обновите её:
   ```powershell
   git checkout main
   git pull
   ```
2. Создайте свою новую ветку:
   ```powershell
   git checkout -b feature/название-вашей-задачи
   ```

---

## 💻 4. Разработка и сохранение (Commit)
Когда вы написали код и проверили его в Unity:
1. Проверьте статус измененных файлов:
   ```powershell
   git status
   ```
2. Добавьте файлы в отслеживание:
   ```powershell
   git add .
   ```
3. Сделайте коммит с понятным описанием:
   ```powershell
   git commit -m "Added player movement and basic sprite animation"
   ```

---

## 🚀 5. Публикация изменений на GitHub (Push)
1. Отправьте вашу ветку на удаленный репозиторий:
   ```powershell
   git push -u origin feature/название-вашей-задачи
   ```
2. Зайдите на **GitHub** в браузере. Нажмите кнопку **«Compare & pull request»**, создайте **Pull Request (PR)** и позовите команду проверить код.

---

## 🧹 6. Очистка веток после успешного слияния (ОБЯЗАТЕЛЬНО!)
После того как твой Pull Request приняли и влили в `main`:
1. **На GitHub:** Нажмите синюю кнопку **«Delete branch»**.
2. **У себя на ПК:**
   ```powershell
   git checkout main
   git pull
   git branch -d feature/название-вашей-задачи
   git fetch --prune
   ```

---

## 🔄 7. Как забрать свежий код товарищей (Pull)
Если кто-то из ребят уже залил свои изменения в `main`:
```powershell
git checkout main
git pull
```

---

## 🛑 8. Золотые правила Unity + Git
* **НИКОГДА** не удаляйте и не трогайте папку `Library/` и `Temp/` вручную.
* У всех участников команды должна стоять **абсолютно одинаковая версия Unity** (**6000.6.7f1**).
* Перед запуском `git add .` убедитесь, что в корне проекта лежит правильный `.gitignore`.
